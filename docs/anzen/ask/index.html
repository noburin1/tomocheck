あやしいメールや画面が来たら、まず撮る。

慌ててリンクを押したり、電話したりしないでください。まず画面を写真に撮って、AIに見てもらうのが安全です。

やることは3つ

1画面を撮る
2質問文をコピーする
3AIを選んで開き、写真を付けて貼る

画面の撮り方

iPhoneの撮り方

サイドボタンと音量を上げるボタンを、同時に押します（ホームボタンがある機種は、ホームボタンとサイドボタンを同時に押します）。撮れた写真は「写真」アプリに入ります。

アンドロイドの撮り方

電源ボタンと音量を下げるボタンを、同時に押します。撮れた写真は「フォト」アプリに入ります。

※機種によって違う場合があります。

AIへの聞き方

まず、この質問文をコピーしてください。

このメール（画面）は怪しくないですか？ 本物か詐欺か、見てください。

AIのアプリで貼り付けてください。

次に、使いたいAIを選んで開き、写真を付けて、コピーした文を貼って送ってください。

七味（Muse）を開く Claudeを開く ChatGPTを開く Geminiを開く Copilotを開く

アプリが入っていればアプリが開きます。入っていなければウェブ版が開きます。

七味を入れてみたい方はこちら（iPhone版のご案内）

送る前に、気をつけること

写真に名前・住所・電話番号などが写っていたら、その部分は送らないでください。

AIの答えは目安です。リンクを押さない・返信しない・書かれた番号に電話しない——これは守ってください。
