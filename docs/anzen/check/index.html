🚫 絶対にしないこと

  • 表示された番号に電話する
  • クレジットカードや銀行の情報を入力する
  • 言われるまま遠隔操作ソフトを入れる
  • コンビニでプリペイドカードを買って番号を教える
  • 「閉じる」以外のボタンや広告を押す

✅ やって大丈夫なこと

  • ブラウザをそのまま閉じる（下に手順あり）
  • パソコンを再起動する
  • 家族や、近くの修理屋さんに画面の写真を見せる
  • 閉じたあと、いつも通り使えているか様子を見る
  • もし電話してしまったら、警察相談 #9110 へ

画面の消し方（閉じられないとき）

  1. まず Esc キーを長押ししてみてください。全画面が解除されることがあります。
  2. ダメなら Alt + F4 を押して、ブラウザを閉じます。
  3. それでもダメなら Ctrl + Shift + Esc で「タスクマネージャー」を開き、使っているブラウザ（Edge / Chrome など）を選んで「タスクの終了」を押します。
  4. 何も効かないときは、電源ボタンを長押しして切っても大丈夫です。大事な作業中のファイルは消えることがあるので、これは最後の手段にしてください。
  5. 再起動後、ブラウザを開いて「前回のページを復元しますか？」と出たら、復元しないを選んでください。
  1. Esc キーを長押しして、全画面を解除してみてください。
  2. Command + Q でブラウザを終了します。
  3. ダメなら Option + Command + Esc で「強制終了」画面を開き、ブラウザを選んで「強制終了」。
  4. 再び開いたときに「ページを復元」と出たら、復元しないでください。
  1. ブラウザのタブ一覧を開いて、そのページのタブだけを閉じます。
  2. 閉じられないときは、アプリ切り替え画面からブラウザを上（または横）にスワイプして終了します。
  3. 「ウイルスが検出されました」と出ても、スマホの設定や公式ストア以外からアプリを入れないでください。

※ 画面を消せたあと、パソコンがいつも通り動いていれば、実際にウイルスに入られた可能性は低いです。詐欺画面の多くは「ブラウザに映った絵」だけだからです。

トモ点検のご案内

このページで測りきれないところを、Windowsの中でじっくり調べる点検アプリです。

トモ点検って、なに？

「元パソコン修理屋の本音」の視聴者向けに作った、Windowsパソコン専用の点検・お手入れアプリです。パソコンにあまり詳しくない方でも迷わないよう、5つの工程を順番に進める形にしてあります。

※ トモ点検はダウンロードして使うWindowsのアプリです。このページの中で動くものではありません。スマホやMacでは使えません。現在の最新版は v1.15.1 です。

5つの工程の流れ

1基本診断最初は状態を見るだけ。何も変更しないので、安心して始められます。
2保護の記録復元ポイントの作成などで、何かあっても「戻れる準備」をします。
3修復Windowsの修復は確認してから実行し、終わったらもう一度状態を確認します。更新がうまくいかないときの診断・修復もここで行います。
4更新WindowsやMicrosoft製品、ストアアプリ、Edge・Chrome・Officeの更新を確認・適用します。自動更新ではドライバーは対象外です。
5結果とレポートやったことを記録に残すので、あとから家族や修理屋さんに見せられます。

※ 工程2では、任意で「まるごとバックアップ」も使えます（システム全体のバックアップ）。

🛡️ 安全への配慮

  • 作業は読み取り専用の診断から始まります
  • 直す・更新する操作は、実行前に必ず確認画面が出ます
  • 始める前に記録（ジャーナル）を書き、実行直前に内容を再確認します
  • 直し作業が同時に重なって動かない仕組みがあります
  • 勝手に再起動はしません

🚀 はじめ方（3ステップ）

  1. 配布ファイルを受け取ったら、フォルダを解凍（展開）します。
  2. 最初に一度だけ 最初に実行_ブロック解除.bat を実行します。ダウンロードした印（ブロック）が付いたままだと起動できないためで、パソコンの設定そのものは変更しません。
  3. 起動.vbs からトモ点検を起動します。詳しくは同梱の 最初にお読みください.txt にも書いてあります。
