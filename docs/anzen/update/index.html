ルーターの更新、
確かめていますか？

ルーターの中にもプログラム（ファームウェア）が入っています。古いままだと、悪さをする人に使われる「穴」が残ることがあります。最新に保つのが、家を守る基本です。

確かめ方は3つ

1ルーターの設定画面を開く
2「ファームウェア更新」の場所で、今の版と「更新を確認」を見る
3新しい版があれば更新する。自動更新の設定があれば、ONにしておくと安心です

設定画面の開き方が分からないときは

ルーター設定ガイドを開く ›
メーカーごとに、設定画面の開き方と更新の場所をまとめています。
更新するときの注意

更新の途中では、ルーターの電源を切らないでください。

更新のあいだ、家のネットは一時的に止まります。

終わると自動で再起動することがあります。そのまま待てば大丈夫です。

家の安全チェックに戻る
