## セキュリティ自己点検について

トモ点検は、配布の前に開発側で脆弱性・安全性の自己点検を行いました。

- 対象：v1.17.0（あとから出した v1.17.1 の変更点についても追補で点検済み）
- 判定：**重大 0件・注意 0件**

点検で確認したこと：

- 通信先は公式の3系統だけです（GitHub の最新版確認、Chrome / Edge の更新確認、Windows Update の仕組み）
- お使いの方の情報（ファイルの場所・機器名・診断結果など）を外へ送信する仕組みはありません
- 勝手に通信することはありません（最新版の確認は、ボタンを押したときだけです）
- インターネットから取得した内容を、そのまま実行することはありません
- パスワードや資格情報を保存する仕組みはありません
- 権限は必要最小限で、削除するのは自分の作ったショートカットなどだけです

正直にお伝えする点（所見）：

- 同梱の「あやしい画面チェッカー」は、相談先として特定のAIサービス（Muse）の画面を案内します（チェッカー自体が何かを送信するわけではありません）
- 配布ファイルには、開発用のテストスクリプトも含まれています
- 診断レポートには機器名などが含まれますが、保存はお使いのパソコンの中だけです

この点検の限界も正直にお伝えします：

- これは**開発側の自己点検**であり、第三者機関の監査ではありません
- 点検はプログラムの中身の静的解析が中心で、通信の実パケットの確認はしていません

詳しくは全文をご覧ください：[セキュリティ自己点検報告書（全文）](docs/security-check-v1.17.md)
